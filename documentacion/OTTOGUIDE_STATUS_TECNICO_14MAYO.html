11
Bug & fix PlayStream
BUG IDENTIFICADO
PlayStream sin audio
Síntoma: PlayStream ret=0 y PlayStop ret=0 pero el robot no emite sonido.
Causa: PlayStop("otto") se llama inmediatamente después de enviar el último chunk de PCM, antes de que el robot termine de reproducirlo. El audio se cancela antes de escucharse.
FIX IMPLEMENTADO
C++ — otto_speak_file.cpp
// duracion = bytes / (16000 * 2) + 1s
double duration_s =
  (double)total / (16000.0 * 2.0);

unitree::common::Sleep(
  (int)duration_s + 1);

ret = client.PlayStop("otto");
Escrito y pusheado — pendiente compilar en Jetson
MECANISMO ALTERNATIVO — play_state via rt/audio_msg
rt/audio_msg — play_state sincronización
"play_state": 1 ← audio comenzó "play_state": 0 ← audio terminó
Este mecanismo permite sincronizar reproducción en lugar de usar Sleep fijo. El suscriptor a rt/audio_msg puede detectar cuándo el parlante terminó de reproducir y proceder a escuchar al usuario.
12
rt/audio_msg — hallazgos
Durante la ejecución del ejemplo oficial, los micrófonos captaron ruido ambiental y el ASR lo transcribió en tiempo real. El tópico publica JSON rico, no texto plano.
rt/audio_msg — ejemplo real capturado sesión 1
{ "index": 13, "timestamp": 1778803269435, "type": 0, "text": "ですよ。", "angle": 0, "speaker_id": 0, "emotion": "<|EMO_UNKNOWN|>", "confidence": 0.500000, "language": "<|ja|>", "is_final": false }
CampoTipoDescripción
indexintNúmero de secuencia
timestamplongTimestamp en ms
textstringTexto transcripto
anglefloatÁngulo del hablante
speaker_idintID del hablante
emotionstringEmoción (Whisper tag)
confidencefloatConfianza 0–1
languagestringIdioma Whisper
is_finalboolFinal o parcial
CÓDIGOS DE IDIOMA WHISPER DETECTADOS
<|yue|> Cantonés <|ja|> Japonés <|en|> Inglés <|es|> Español ← esperado para Otto <|zh|> Chino mandarín
Implicación clave para el pipeline
El ASR integrado del robot ya funciona y está activo. Es Whisper-based y soporta español. El nodo STT puede suscribirse directamente a rt/audio_msg usando el subscriber de tipo std_msgs::msg::dds_::String_. El campo m→data() contiene el JSON completo para parsear con nlohmann/json.
